# سایت من

یک وب‌سایت چندصفحه‌ای، فارسی و راست‌به‌چپ، ساخته‌شده فقط با **HTML، CSS و JavaScript خالص**. بدون فریم‌ورک، بدون کتابخانه، بدون مرحله‌ی build.

## درباره‌ی پروژه

تمام مراحل این پروژه، از ایده و طراحی تا نوشتن کد، اشکال‌زدایی، بهینه‌سازی و نوشتن همین مستند، با کمک هوش مصنوعی انجام شده است:

- **Claude** (ساخته‌ی Anthropic)
- **ChatGPT** (ساخته‌ی OpenAI)

این مخزن نمونه‌ای از ساخت یک سایت کامل با همکاری انسان و هوش مصنوعی است. کد در این مخزن آزادانه قابل استفاده، تغییر و یادگیریه.

## ویژگی‌ها

- مسیریابی سمت کلاینت با `hash` (خانه، درباره، خدمات، تماس) بدون ریلود صفحه
- حالت شب و روز؛ انتخاب کاربر ذخیره می‌شه و در اولین ورود از تنظیم سیستم پیروی می‌کنه
- طراحی ریسپانسیو با منوی همبرگری برای موبایل
- شمارنده‌ی عددها و تایپ‌شدن متن با ارقام و ریتم فارسی
- فرم تماس نمایشی با بازخورد بصری
- یک فایل JavaScript که CSS و صفحات رو خودش مدیریت می‌کنه

### انیمیشن‌ها و جلوه‌ها

- شبکه‌ی ذرات روی بوم (canvas) که به حرکت ماوس واکنش نشون می‌ده
- بلوب‌های شناور پس‌زمینه با افکت پارالاکس
- نوار پیشرفت اسکرول در بالای صفحه
- کارت‌ها با ورود چرخشی، چرخش سه‌بعدی (tilt) و نور دنبال‌کننده‌ی ماوس
- آیکون‌های شناور با تکان‌خوردن موقع هاور
- دکمه‌های مغناطیسی با افکت موج (ripple) و درخشش پالسی
- خط گرادیانی که زیر تیترها باز می‌شه
- کانفتی بعد از ارسال فرم
- متن گرادیانی متحرک
- نشانگر سفارشی ماوس با حلقه‌ی دنبال‌کننده و بزرگ‌شدن روی عناصر تعاملی
- پرده‌ی گرادیانی هنگام جابه‌جایی بین صفحه‌ها
- ترقه‌ی ذره‌ای با هر کلیک
- نوار متحرک کلمات (marquee) در صفحه‌ی اصلی
- متن عنوان صفحه‌ها با افکت رمزگشایی
- بخش اصلی با چرخش سه‌بعدی ملایم و پارالاکس هنگام اسکرول

## دسترسی‌پذیری و عملکرد

- احترام به `prefers-reduced-motion`؛ اگه کاربر انیمیشن کم رو انتخاب کرده باشه، ذرات، کانفتی و افکت‌های حرکتی خاموش می‌شن
- پشتیبانی از ناوبری با کیبورد، `aria-label`، `aria-current` و `focus-visible`
- بسته‌شدن منوی موبایل با `Escape` و کلیک بیرون
- متوقف شدن انیمیشن بوم وقتی تب فعال نیست
- کنتراست مناسب در هر دو تم

## ساختار فایل‌ها

```
.
├── index.html   # اسکلت صفحه
├── script.js    # منطق، صفحات و استایل (CSS داخل همین فایل تزریق می‌شه)
└── README.md
```

## اجرا

نیازی به نصب چیزی نیست. یکی از این دو راه رو برو:

1. فایل `index.html` رو مستقیم توی مرورگر باز کن.
2. یا با یک سرور ساده اجرا کن:

```bash
python3 -m http.server 8000
```

بعد برو به `http://localhost:8000`.

## انتشار روی GitHub Pages

1. مخزن رو روی گیت‌هاب بساز و فایل‌ها رو پوش کن.
2. بخش **Settings → Pages** رو باز کن.
3. شاخه‌ی `main` و پوشه‌ی `/ (root)` رو انتخاب کن و ذخیره بزن.
4. بعد از چند دقیقه سایت روی `https://USERNAME.github.io/REPO` در دسترسه.

## شخصی‌سازی

- **رنگ‌ها:** متغیرهای `--purple`، `--cyan` و `--pink` در ابتدای CSS داخل `script.js`
- **متن صفحات:** توابع `pageHome`، `pageAbout`، `pageServices` و `pageContact`
- **نام سایت و متن تایپ‌شونده:** ثابت‌های `SITE_NAME` و `TYPING_TEXT` بالای فایل
- **صفحه‌ی جدید:** یک تابع بساز و توی آبجکت `routes` و تابع `makeHeader` اضافه‌ش کن
- **فرم تماس:** فعلاً فقط نمایشیه. برای ارسال واقعی می‌تونی به سرویس‌هایی مثل Formspree یا Netlify Forms وصلش کنی.

## نکته‌ی امنیتی

این پروژه کاملاً سمت کلاینته و هر کدی که توی `script.js` هست برای همه قابل مشاهده‌ست. هیچ کلید API، رمز یا اطلاعات حساسی داخلش نذار.

## سازگاری مرورگرها

نسخه‌های جدید Chrome، Edge، Firefox و Safari. از قابلیت‌هایی مثل `IntersectionObserver`، `backdrop-filter`، `dvh` و `Intl.NumberFormat` استفاده شده.
